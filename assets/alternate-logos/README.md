Optimized alternate branding for DexCast. These assets preserve the established Dexter mascot and the "Sit With Dexter" identity.

- `dexcast-primary-mascot.png` — primary mascot lockup
- `dexcast-circular-broadcast.png` — circular broadcast/app-badge variant

## Optimization

The archived PNGs are 512x512 PNG8 assets with metadata stripped and palette/compression optimized for repository distribution and UI/prototype use.

The featured primary mascot asset is retained at a slightly larger optimized raster size for cases where extra headroom is useful.

These are alternate assets only. They do not replace `assets/AppIcon.icns` or the existing Dexter state artwork.
